# 🛒 Lista de Compras - App React Native

Um aplicativo moderno e elegante para gerenciamento de compras, desenvolvido com **React Native** e **Expo**. 

Este projeto foi construído para demonstrar a aplicação prática de hooks e listas no ecossistema React, focando em performance, imutabilidade e boas práticas de UI/UX para dispositivos móveis.

## Funcionalidades

- **Adicionar Itens:** Inserção de novos itens na lista utilizando `TextInput` e controle de estado com `useState`.
- **Remover Itens:** Exclusão individual de itens da lista de forma dinâmica e imutável.
- **Validação Inteligente:** O botão de adicionar é desativado visualmente e funcionalmente se o campo estiver vazio.
- **Lista Eficiente:** Renderização de alta performance utilizando o componente nativo `FlatList` com chaves únicas geradas dinamicamente.
- **Empty State:** Interface amigável que avisa o usuário quando a lista está vazia.
- **Design Moderno:** Layout limpo com cantos arredondados, sombras suaves e cores responsivas, adaptado para iOS e Android (`KeyboardAvoidingView` implementado).

## Como rodar o projeto localmente

Siga os passos abaixo para testar o aplicativo no seu ambiente:

1. **Clone o repositório ou baixe os arquivos** para sua máquina.
2. **Abra o terminal** na pasta raiz do projeto.
3. **Instale as dependências** do projeto usando o comando:
   ```bash
   npx expo install
   ```
4. **Inicie o servidor de desenvolvimento** do Expo:
   ```bash
   npx expo start
   ```
5. **Teste no seu dispositivo:**
   - Escaneie o QR Code exibido no terminal usando o aplicativo **Expo Go** no seu celular (Android/iOS).
   - Ou pressione `a` para rodar no Emulador Android, ou `i` para rodar no Simulador iOS (caso os tenha configurados na sua máquina).
   - Ou pressione `w` para testar diretamente no navegador web.
